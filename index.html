Por que aprender Hermes Agent?

Hermes Agent é um agente de IA open source (MIT) da Nous Research que cria suas próprias skills, mantém memória persistente entre sessões e conecta 200+ modelos via OpenRouter. Roda em VPS, Docker, SSH, Modal, Vercel Sandbox e AWS Bedrock AgentCore.

🧠

Aprendizado autônomo

Cria skills sozinho a partir das tarefas que executa. Memória persistente curada pelo próprio agente, busca FTS5 em sessões passadas.

🌐

Multi-canal nativo

Gateway unificado para Telegram, Discord, Slack, WhatsApp, Signal. Um processo, todos os canais.

🔌

Extensível por padrão

Suporte nativo a MCP (Model Context Protocol), Tool Gateway e padrão aberto agentskills.io.
